## Making a commit locally

we want to track the file, so we need to commit it. 

Commiting locally requires two steps:
1. stage the file(s) to include in the commit, which is a snapshot of the directory at this point in time
1. create the commit (take the snapshot)

the two step process allows us to, for example edit several files and then only commit changes to some of them, or make separate commits for different edits. 

+++{"lesson_part": "main"}

A lot of the time, we want to stage everything. We can use the `.` which is a special file for the current location to do that. 

we use `git add` to {term}`add` files to the staging area. 

```{code-cell} bash
:tags: ["skip-execution"]
git add .
```

+++{"lesson_part": "main","type":"output"}

```{code-block} console
```

+++{"lesson_part": "main"}
it has no output, but git status will let us see what changed. 
```{code-cell} bash
:tags: ["skip-execution"]
git status
```

+++{"lesson_part": "main","type":"output"}

```{code-block} console
On branch 2-create-an-about-file
Your branch is up to date with 'origin/2-create-an-about-file'.

Changes to be committed:
  (use "git restore --staged <file>..." to unstage)
	new file:   about.md

```
Now the files are staged "to be committed"


:::::{attention}
Notice that each time, `git status` has a hint about what you might want to do next or to undo what you just did
:::::::


Notice that now the file is `to be comitted` intead of `untracked`

## Questions After Today's Class 

### Is the local workspace used in the real world?

Yes, mostly in fact. Even if you work on e.g. an HPC system, you work locally on that system.  You cannot run code on the git server, at all.  Even github actions work "locally" just on a virtual machine. 

Local is relative. 

### How can I see it in the folder of my desktop?

If you put your folder in your desktop folder, your regular file explorer or desktop should show. 

If you mean desktop computer, like another physical device, you have to clone it there. 

### What's a good way of memorizing the smaller commands?

Practice! and quizzing yourself. 

We will practice, **a lot** in class and I'll use prismia questions to quiz you some. Plus the review and practice badges will give you more instructions to practice with these commands. 

### How can I make a Pull Request to the course website repo?

at the top of the page there is a [link to this repo](https://github.com/compsys-progtools/spring2026) (the github icon) but it's also linked there. 

Then find the file you want to add to (for this page, `notes/2026-01-29.md`) then use the pencil icon to edit.  It will have you make a fork and then it will work just like a normal PR that we have done before. 

Also the [github docs](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/creating-a-pull-request-from-a-fork) have screenshots and more detailed instructions. 

I do recommend trying to remember first though.
