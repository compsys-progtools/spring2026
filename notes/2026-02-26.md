## What about goign backwards

`git revert` lets use **add** a new commit that contains the opposite changes of the commit that we want to revert. 

For example, my commit [`694223d`](#descadd) adds the table description, so reverting will remove it. 

```{code-cell} bash
:tags: ["skip-execution"]
git revert 694223d
```
