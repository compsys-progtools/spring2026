## Managing Tasks with issues 


1. Navigate to your issues tab of your KWL {term}`repo`
2. Create an issue using the [content below](#about)
3. In the right panel, under `Development` click "create a branch"
4. Leave the default settings and then create the branch
5. close the popup with commands, we will learn them later
6. Click the branch under `Development` to go to the Code tab on that new branch (e.g. `7-create-about`, but your number might be different)
7. Begin to edit the file
8. Commit changes directly to the branch named for the issue (e.g. `7-create-about`, but your number might be different)
9. Go to the pull Request tab
10. Create a pull request with `head:main` and `compare:7-create-about` with your actual branch name
11. Mark the pull request as a draft using the link on the right hand side
