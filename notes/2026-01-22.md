### Why is git and github used frequently in the computer science world?

Keeping track of versions has been done for a very long time.  git is so much better than all of the previous version control systems it's basically all anyone uses anymore.  Even really big legacy code bases that have decades of work in another version control system are movign to git. 

git is super fast and distributed. plus some other advantages.  We will answer this question throughout the semester as we unpack the details of how git works


### If you make another brance separate from your main one, if you want to do a pull request/merge it with the main branch does it take only the information from the last commit?

No, when you merge two branches all of the commits from the compare branch are added to the base branch. 


### How does the new content show up after you have merged it to the main branch (ie. is it at the bottom, is it at the top, is it in the middle, etc.)

The content will be in the place you put it on the new branch. The commits will generally be the most recent, but this can vary.
